## Applied styles

- Primary button blue: #007fae; logo blue: #0087b7.
- Turquoise accents: #00bfb6.
- Primary text: #1b1b1b; secondary text: #464646/#7d7d7d.
- White backgrounds, light gray borders (#e6e6e6), restrained panel shadows.
- The source site uses neue-haas-unica. The application declares it with Helvetica Neue/Arial fallbacks; no proprietary font files or site-specific Typekit kit are copied or loaded. Exact font rendering depends on installed fonts.
- The official logo links back to Buildwise. The welcome page has a two-column desktop layout and a single-column mobile layout.

This is a source-backed visual reference for this application, not an official complete corporate brand manual.
