## Persistence and limitations

The shipped snapshot is [data/project-tags.json](../../data/project-tags.json). Completed scans, including missing/short results, are retained indefinitely and skipped before description reads. Later Odoo edits, new versions or changed extraction rules do not invalidate them. Failed source reads remain retryable. An explicit manual reset would be required to scan an existing completed project again.

Each record keeps exact project/source identity, description-version ID/date, a SHA-256 summary fingerprint, quality status and scan timestamp. Full source HTML/narratives and credentials are not shipped. English/French/Dutch labels accompany canonical tag IDs. These are reviewed suggestions, not existing Odoo tags. No Odoo data was changed.

The scope is the currently readable unit-206 catalogue, not every project that mentions a digital topic across other units. All 50 currently returned projects were reconciled to a unique exact ID and owned version. Current descriptions may evolve after this frozen scan.
